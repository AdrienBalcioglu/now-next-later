# Now / Next / Later

A date-free product roadmap board: now, next, later.
**[Try it live](https://adrienbalcioglu.github.io/now-next-later/)**


## Features

- Three columns with drag and drop, and arrow buttons for keyboard and touch
- Cards with a title, an outcome and a theme
- Copy the roadmap as Markdown, or print it to PDF
- Saved locally

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Your data is saved in the browser's local storage and never leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
